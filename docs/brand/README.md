# planj mark

- `pj-mark.svg` — the primary mark: pj drawn from Shrikhand's outlines (SIL Open Font License),
  the j's own dot removed and replaced by the teal planj dot (#2EC4B6), a teal swash beneath.
- `pj-outlines.json` — the letter outlines in font units (y down), for `pj` and `planj`, with
  the dot's centre and radius. The Android icon and splash are generated from these.

Colours: letters #EDEFF2 on #0E1113, dot and swash #2EC4B6.
The design board with colourways, wordmark, badge and the launch storyboard lives in the
"planj icon exploration" canvas artifact.
